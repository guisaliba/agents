# Harness map for the global instructions

`~/.claude/CLAUDE.md` is an unchanged copy of the global `AGENTS.md` from
`guisaliba/agents`. That file names a few OpenCode objects. In Claude Code, use
these equivalents:

- "the `question` tool" means the `AskUserQuestion` tool.
- "generated ai-memory routing from `~/.config/opencode/ai-memory.md`" means
  the generated routing in `~/.claude/rules/ai-memory.md`.

This file is managed by `guisaliba/agents/apply.sh`. Edit the repository copy,
not this file.
