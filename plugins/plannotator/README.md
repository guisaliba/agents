# Plannotator

Plannotator provides plan review, code review, file annotation, and visual
explanation workflows for OpenCode.

Apply installs the `@plannotator/opencode@latest` plugin and the commands at
`~/.config/opencode/commands/plannotator-*`. Its shared skills are installed
by the installer and are not vendored here.

Useful commands:

```sh
plannotator review [pr-url]
plannotator annotate <file|url|folder>
plannotator last
```
